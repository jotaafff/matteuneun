# 마뜨는구간삭제 — Windows MVP

**영상에서 사람의 말소리가 없는 구간을 0.01초 단위로 탐지하고, 사용자가 검토·선택한 구간만 삭제해 MP4로 저장하는 데스크톱 프로그램입니다.**

## 현재 구현 기능

- 유튜브 URL 입력 또는 컴퓨터의 영상 파일 선택
- FFmpeg로 오디오를 16kHz 모노 PCM으로 추출
- WebRTC VAD를 이용한 10ms(0.01초) 프레임 음성 활동 감지
- 최소 삭제 후보 길이, 음성 보호 여백, VAD 민감도 설정
- 탐지한 각 구간별 `삭제 전후 비교` 버튼
- 비교 범위: 삭제 후보 앞 최대 7초부터 후보 뒤 최대 7초까지
- 비교 창에서 삭제 전 영상, 삭제 후 영상, 좌우 분할 비교 영상 재생
- 행마다 삭제 대상 선택, 전체 선택/해제
- 선택한 구간만 잘라 이어 붙여 MP4로 저장
- 원본 파일은 수정하지 않음

## 설치 환경

- Windows 10/11 (64비트 권장)
- Python 3.11 이상
- FFmpeg 및 ffprobe
- 인터넷 연결(패키지 설치 및 유튜브 URL 사용 시)

## 설치 순서

### 1. Python 설치

Python 3.11 이상을 설치하세요. 설치 과정에서 Python Launcher와 PATH 등록 옵션을 활성화하는 것이 좋습니다.

### 2. FFmpeg 설치

FFmpeg는 별도 설치 프로그램입니다. FFmpeg의 `ffmpeg.exe`와 `ffprobe.exe`가 들어 있는 `bin` 폴더를 Windows PATH에 추가해야 합니다.

설치 확인은 새 명령 프롬프트에서 아래 명령을 실행하면 됩니다.

```bat
ffmpeg -version
ffprobe -version
```

두 명령 모두 버전 정보를 출력해야 합니다. FFmpeg 공식 다운로드 안내: https://ffmpeg.org/download.html

### 3. 파이썬 패키지 설치

압축을 푼 폴더에서 `install_windows.bat`을 더블클릭하세요. 이 스크립트가 가상환경을 만들고 `requirements.txt` 패키지를 설치합니다.

### 4. 프로그램 실행

`run_windows.bat`을 더블클릭하세요.

## 기본 사용법

1. 유튜브 URL을 붙여넣거나 `파일 선택`으로 로컬 영상을 고릅니다. 둘 다 입력한 경우 로컬 파일을 우선 사용합니다.
2. 분석 설정을 정하고 `음성 없는 구간 분석`을 누릅니다.
3. 결과 행에서 `삭제 전후 비교`를 눌러 검토합니다.
4. 비교 창에는 후보 구간 앞뒤 최대 7초를 포함한 영상이 준비됩니다. 좌우 분할 화면은 무음 시각 비교용이며, 삭제 전·후 개별 재생 버튼은 원본 오디오가 포함된 영상을 엽니다.
5. 실제로 제거할 구간만 `삭제 대상으로 선택`에 체크합니다.
6. `선택 구간 삭제 후 영상 저장`을 눌러 새 MP4로 내보냅니다.

## 분석 기준과 한계

- 분석 프레임은 16kHz 모노 PCM의 10ms 단위입니다. 따라서 결과 시각은 0.01초 단위로 표시됩니다.
- 실제 영상 컷은 원본 영상의 프레임 경계에 영향을 받습니다. 예를 들어 30fps 영상은 개별 프레임 간격이 약 0.033초이므로 영상 화면의 컷 지점이 0.01초 격자와 정확히 일치하지 않을 수 있습니다.
- WebRTC VAD는 음성 활동 감지기입니다. 사람 말소리가 없는 배경음악이나 효과음을 항상 완벽하게 구분하는 음성 인식 모델은 아닙니다. 음악·악기·효과음이 음성으로 오인되거나, 작고 잡음이 많은 말소리를 놓칠 수 있습니다.
- 민감도 0은 음성으로 판정하는 범위가 넓고, 3은 더 엄격하게 판정합니다. 결과가 마음에 들지 않으면 민감도와 최소 길이를 조정해 다시 분석하세요.
- 음성 주변의 자음·숨소리 등이 잘리지 않도록 기본 0.10초 보호 여백을 양쪽에 적용합니다. 이 값은 조정할 수 있습니다.
- 비교 화면의 좌우 분할 영상은 무음입니다. 원본 오디오를 듣고 판단하려면 비교 창의 `삭제 전 영상 재생`과 `삭제 후 영상 재생`을 각각 이용하세요.
- 원본 영상 파일에는 쓰기 작업을 하지 않습니다. 삭제 선택은 내보내기 결과에만 적용됩니다.

## 유튜브 URL 이용 안내

URL 다운로드는 `yt-dlp`를 사용합니다. 본인이 소유하거나 다운로드·편집할 권한이 있는 콘텐츠에 사용하세요. 비공개, 유료, 연령·지역 제한, 로그인 필요 영상은 가져오지 못할 수 있습니다. YouTube 변경에 따라 yt-dlp가 최신 버전이어야 하며, 일부 환경에서는 JavaScript 런타임 설치가 추가로 필요할 수 있습니다. URL 처리에 실패하면 허용된 방법으로 확보한 영상 파일을 직접 업로드하세요.
